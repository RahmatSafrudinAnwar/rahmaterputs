PRAKTIKUM ERP - PHP + MySQL + Bootstrap 5 + DataTables
Laragon/XAMPP: Start Apache + MySQL, salin folder ke www/htdocs, buka http://localhost/praktikum-erp
Database erp_praktikum dibuat otomatis (root, tanpa password; ubah di config.php). Atau impor database.sql lewat phpMyAdmin.
Folder data/backup dipakai demo backup di Praktikum 2 (harus bisa ditulis).
